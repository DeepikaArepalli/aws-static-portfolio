# AWS S3 Static Portfolio Website

##  Project Overview
This project demonstrates how to host a static portfolio website using **Amazon S3**. The website is built using **HTML, CSS, and JavaScript** and deployed as a public static website on AWS.

This project helped me gain practical experience with AWS Cloud services and understand how static website hosting works.

##  Project Objectives
* Build a simple static portfolio website.
* Host the website using Amazon S3.
* Configure static website hosting.
* Manage public access and bucket policies.
* Deploy a live website on AWS.

##  Technologies Used
* Amazon S3
* HTML5
* CSS3
* JavaScript
* GitHub
##  What I Learned
* Creating and configuring Amazon S3 buckets.
* Hosting static websites on AWS.
* Understanding bucket policies and permissions.
* Managing public access securely.
* Deploying a website to the cloud.
* Organizing and documenting a cloud project with GitHub.
* Amazon S3
